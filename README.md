# stimul.ai
An AR experience about visual stimuli. 

Explore your spatial surroundings with the help of AI. Discover details you might have missed and learn about the world that surrounds you in unexpected ways. 

We built this project because our human minds tend to filter out many of the stimuli that our bodies transmit. We wanted to explore how a removal of such a filter may look like and how this could change our perception.

This project was built for the ArtTechHack 2026 taking place at ETH Zurich.

## setup
- start the llama.cpp instance in the local network
- run npm install in /web
- run npm run dev in /web
- more info on the setup is detailed in the CLAUDE.md
